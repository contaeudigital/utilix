Regra de 3 (Simples)

Use a regra de 3 para calcular X em uma proporção. Preencha os valores e deixe um campo como X. Exemplo: se 2 custam 10, quanto custam 5? (2 → 10 / 5 → X)

Preencha A, B, C e deixe X vazio para calcular.

Fórmula: A : B = C : X → X = (B × C) ÷ A
(Se você deixar outro campo vazio, também calculamos automaticamente.)

Perguntas frequentes

Quando usar regra de 3?
Quando duas grandezas são proporcionais e você quer descobrir um valor desconhecido usando a relação entre elas.

Regra de 3 simples vs composta
Aqui é a simples (duas grandezas). A composta envolve mais grandezas (podemos adicionar depois).
